## 🚀 Key Features

- **Typography-First Hero Section**: Massive fluid Kanit typography headline with smooth gradient text.
- **Scroll-Driven Character Reveal**: Character-by-character opacity reveal animation in the About section.
- **Services Showcase**: Clean curved white card highlighting core technical specializations:
  - 01 Workflow Automation & n8n
  - 02 AI & WhatsApp Chatbots
  - 03 Machine Learning & Predictive Systems
  - 04 Modern Web Design & Frontend
  - 05 API Integrations & Backend Scripts
- **Sticky-Stacking Projects**: Interactive cards scaling dynamically on scroll, highlighting real repositories:
  - House Price Prediction Model (Python / ML)
  - n8n Workflow Automation Engine
  - AI-Powered CV Filtering System
  - Custom WhatsApp AI Chatbot
- **Interactive Contact Experience**: Glassmorphic modal with 1-click email copy, direct phone dial, and project inquiry form.

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/muhammadbilaliiui/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
